# 火线行动：消防安全挑战

移动端消防安全科普 H5 互动游戏（Vue 3 + Vite + TypeScript）。  
版本：**1.0.0** · 纯前端静态站点，无登录、无后端。

线上演示：https://liuliu521789.github.io/fire-safety-h5/

> 本作品用于消防安全科普宣传与互动演练，**不构成专业资质、培训合格或上岗证明**。真实火场请以自身安全为先，及时拨打 **119**。

## 关卡与分值（满分 100）

| 关卡 | 内容 | 满分 |
|------|------|------|
| 01 隐患排查 | 家庭场景点击找隐患 | 20 |
| 02 火场逃生 | 知识题 + 逃生跑图 | 20 |
| 03 初起灭火 | 灭火器「提、拔、握、压」 | 20 |
| 04 紧急报警 | 模拟拨打 119 报警流程 | 15 |
| 05 火线救援 | 互助转移演练（强调先自保） | 25 |

## 开发与构建

```bash
npm install
npm run dev      # 本地预览
npm run build    # 产出 dist/
npm run preview  # 预览构建结果
```

- 设计基准：390 × 844
- 路由：Hash（`#/`），便于静态托管与微信内打开
- 部署：推送 `main` 后由 GitHub Actions 发布至 GitHub Pages

## 浏览器兼容（建议验收矩阵）

| 环境 | 说明 |
|------|------|

## 隐私说明

- 仅使用浏览器 `localStorage` 保存进度、音效开关与证书姓名（本地）。
- 证书分享链接可携带成绩快照（URL 参数），便于微信内打开不丢分；请勿将含姓名的链接公开发布到不信任场合。
